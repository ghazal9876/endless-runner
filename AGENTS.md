# Endless Runner

This is a dependency-free browser game contained in `index.html`.

- Keep gameplay and rendering in the existing canvas loop.
- Preserve the three-lane controls: Left/Right arrow keys change lanes one step at a time.
- Keep visuals night-sky themed and ensure obstacles remain easy to see against the background.
- Test changes by opening `index.html` in a modern browser.
- Do not add a framework or build step unless explicitly requested.
